# 📜 O que são Commits?

Commits são como "fotos" do seu projeto em um determinado momento. Eles registram as alterações feitas no código, criando um histórico que permite voltar a versões anteriores, entender o que foi modificado e colaborar de forma eficiente com outras pessoas.

De forma simples:
- Um commit é uma maneira de salvar as mudanças que você fez no código.

- Cada commit tem uma mensagem que descreve o que foi alterado.

- Esses registros ajudam a manter o projeto organizado e facilitam a identificação de problemas ou melhorias.

## ⚙️ Como Funciona um Commit?

- Alterações no Código: Você faz mudanças nos arquivos do projeto, como adicionar novas funcionalidades, corrigir bugs ou atualizar documentação.

- Preparação (Staging): Usando git add, você seleciona quais alterações deseja incluir no próximo commit.

- Criação do Commit: Com git commit, você salva essas alterações no histórico do projeto, junto com uma mensagem descritiva.

- Histórico: Cada commit é armazenado no repositório, criando uma linha do tempo de todas as alterações feitas.

## ❓ Por que Commits São Importantes?

- Histórico de Alterações: Permite ver o que foi feito, quando e por quem.

- Colaboração: Facilita o trabalho em equipe, pois todos podem ver as mudanças e entender o progresso do projeto.

- Segurança: Se algo der errado, você pode voltar a um commit anterior e restaurar o projeto.

- Organização: Commits bem descritos ajudam a manter o projeto organizado e fácil de entender.
